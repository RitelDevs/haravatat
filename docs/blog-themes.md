# 博客主题（第一版）

账号管理的「博客主题」进入 `/account/theme`。选择森林、海洋、梅紫配色，衬线/无衬线阅读字体，卡片/列表首页布局，以及无封面/渐变封面。字体来自设备系统，不加载远程字体；渐变由本站 CSS 生成，没有封面上传或外部资源。预览包含卡片、正文与真实 KaTeX 数学渲染，修改仅影响当前预览。点击「保存主题」后访问者的新请求看到新主题；失败保留草稿以便重试。「撤销预览修改」还原上次保存状态，「恢复默认预览」载入默认森林/衬线/卡片/无封面，仍需保存才会公开生效。

作用域为 `/?author=GitHub用户名` 的作者博客首页，以及该作者全部 `/p/:id` 文章。作者名链接可进入博客，账号管理也提供「查看我的博客」。首页有身份信息，即使尚未发布文章也可访问。站点发现首页、页首导航、工作台和账号管理保持站点外观。主题和界面中英文、亮/暗/跟随系统偏好独立：作者决定主题，读者决定语言及明暗。三个配色均提供明暗变量；目录、正文和公式继承，PDF 纸张/文字/插图保持编译文档原样，阅读器周围配色跟随主题。

`shared/blog-theme.ts` 定义严格的版本 1 配置，仅接受枚举，不接收 CSS、HTML、字体 URL、图片 URL 或任意颜色。设置保存在 `blog_themes(user_id, settings jsonb)`，以 GitHub 数字 ID 绑定，OAuth 资料更新不会覆盖主题；账号注销级联删除。没有记录的旧账号使用默认配置，迁移幂等且不重写内容。读取未知/损坏配置时回退默认；未来版本需显式迁移并更新共享解析器。

接口：公开 `GET /api/blogs/:login` 返回身份和已保存主题；文章详情也带同一主题。私有 `GET /api/account/theme` 与 `PUT /api/account/theme` 读取/保存当前账号配置，不接受目标用户 ID，写入沿用会话、Origin、请求头保护，在用户行锁后复核会话防止注销后旧请求回写。保存整份配置，以最后一次成功保存为准，不自动合并并发标签页。API 为 no-store；已打开的页面保留加载时主题，刷新后更新。

暂不支持任意自定义 CSS，避免影响导航、隐藏安全提示或通过 CSS URL 加载外部资源。主题通过 `.blog-theme` 范围内的固定 data 属性和语义变量生效，表单选择不拼接选择器或 style 字符串。扩展配色/字体/封面必须先加入枚举和受限 CSS，再补明暗对比度、移动端、数学、目录和 PDF 回归；若未来允许 CSS，需另行设计资源隔离及与站点界面分离的沙箱，不能直接注入全站样式。
